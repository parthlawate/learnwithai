# learnwithai
Simple Tools & Games to help parents help their kids with homework, exam prep etc using AI.

## Repository Structure

```
medium/
└── marathi/
    ├── extract_marathi_textbook.py      # Automated pipeline script for extracting Balbharati PDFs
    └── grade3/
        └── marathi/
            ├── Grade_3_Marathi_Balbharati.html          # Interactive, styled HTML reader with TOC & search
            ├── Grade_3_Marathi_Balbharati_Complete.md   # Complete 100-page Unicode Marathi textbook
            ├── part_1.md                                # Unit 1 (Lessons 1-6)
            ├── part_2.md                                # Unit 2 (Lessons 7-11)
            ├── part_3.md                                # Unit 3 (Lessons 12-17)
            ├── part_4.md                                # Unit 4 (Lessons 18-22 + Santavani)
            └── README.md
```

## Features
- **Full Unicode Devanagari Transcription**: Solves the legacy font encoding issues (Shree-Lipi / Balbharati WinAnsi) in Maharashtra State Board Balbharati textbook PDFs.
- **Interactive HTML Reader**: Includes search, dark/light theme, font size adjustment, and print-ready stylesheet.
- **Comprehensive Content**: Covers all poems, prose stories, grammar exercises (*खेळू या शब्दांशी*, *आपण समजून घेऊ या*), vocabulary (*नवीन शब्द शिकू या*), and exercises (*स्वाध्याय*).
