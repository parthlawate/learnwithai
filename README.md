# 🎓 learnwithai

> **Transforming Homework Battles into Innovation Labs.**  
> An open-source ecosystem of **LLM-ready regional curriculum assets, NEP/NCF-aligned pedagogical frameworks, and interactive HTML5 AI games** that turn everyday study resistance into joyful, multi-modal learning adventures for kids, parents, and teachers.

---

## 💡 The Origin: When 9:30 PM Homework Resistance Became an Innovation Lab

Every parent knows the dreaded 9:30 PM weekday scenario: a defeated child staring blankly at repetitive homework notebooks, bargaining for time, while parents struggle to enforce rote drills (*"Write numbers 1 to 100 in words again"*, *"Copy these 20 words five times"*).

Rote practice kills curiosity. But the core skills—letter formation, place values, vocabulary, linguistic nuance—are essential. 

Inspired by the journey documented in [Abhyas Bibhyas: When 9:30 PM Homework Resistance Became Innovation Lab](https://magicofcreation.substack.com/p/abhyas-bibhyas-when-930-pm-homework), **`learnwithai`** is built on a fundamental shift:

$$\text{From Push Learning: } \textit{“Do I have to do homework?”} \implies \text{To Pull Learning: } \textit{“Can we play the study game?”}$$

## 🏛️ Grounded in NEP 2020 & National Curriculum Framework (NCF)

`learnwithai` is architected from the ground up to support India’'s **National Education Policy (NEP 2020)** and **National Curriculum Framework (NCF-FS & NCF-SE)** across **all Indian languages, mediums, and stages**:

```
+---------------------------------------------------------------------------------------------------+
|                                 NEP 2020 / NCF 5+3+3+4 STAGES                                     |
+---------------------------------------------------------------------------------------------------+
|  1. Foundational (Ages 3-8 / Grades Nursery-2) : Play, discovery, FLN (NIPUN Bharat), Phonics    |
|  2. Preparatory  (Ages 8-11 / Grades 3-5)      : Multi-modal activity, reading comprehension      |
|  3. Middle       (Ages 11-14 / Grades 6-8)     : Experiential science, math reasoning, puzzles   |
|  4. Secondary    (Ages 14-18 / Grades 9-12)    : Critical thinking, problem-solving, debates      |
+---------------------------------------------------------------------------------------------------+
```

### 🌟 Core Pedagogical Pillars:
1. **The 5-Fold Holistic Learning (Panchakosha Theory in NCF)**:
   - **Annamaya Kosha (Physical)**: Kinesthetic movement, active play, gestures during learning.
   - **Pranamaya Kosha (Energy)**: Rhythm, recitation, singing, breathing.
   - **Manomaya Kosha (Emotional/Mind)**: Child agency, theme selection, playful storytelling.
   - **Vijnanamaya Kosha (Intellect)**: Critical thinking, puzzles, math reasoning, grammar quests.
   - **Anandamaya Kosha (Bliss/Joy)**: Intrinsic motivation, celebration of small wins.

2. **Multilingual First (मातृभाषा / Regional Mediums)**:
   - Genuine high-fidelity digitization for regional languages (Marathi, Hindi, Gujarati, Tamil, Telugu, Kannada, Bengali, etc.), eliminating legacy font barriers.

3. **Low Screen Time, High Physical Engagement ("Phygital")**:
   - The screen is used for **seconds** (to roll dice, generate a quest, or pick a card).
   - The actual learning happens **in the real world** (writing in notebooks, jumping, drawing, discussing with parents, singing).

## 🎯 The Multi-Modal Learning Matrix

Instead of forcing a child to only write, `learnwithai` games and AI prompts dynamically transform any curriculum topic across multiple expression modalities:

| Modality | Learning Style | Example Activity Generated by AI |
| :--- | :--- | :--- |
| 🗣️ **Verbal** | Linguistic & Auditory | *"Explain to the dinosaur ranger how you calculated place value for 48."* |
| ✍️ **Written** | Fine-Motor & Visual Memory | *"Write the 3-letter rhyming words as secret codes to enter the fort."* |
| 🏃 **Physical Play** | Kinesthetic (Body Movement) | *"Jump like a kangaroo as many times as the answer to $6 \times 4$."* |
| 🎨 **Drawing & Craft** | Spatial & Creative | *"Draw a tree with 5 branches, and write one Marathi synonym on each leaf."* |
| 🎵 **Singing & Rhythm** | Musical & Memory Retention | *"Sing the multiplication table of 7 in a rap rhythm with clapping."* |

## 🎮 HTML5 AI Game Engines & Frameworks (Cross-Medium, Cross-Grade)

The repository provides plug-and-play HTML5 web games powered by client-side logic and multimodal LLMs (Gemini / Claude / GPT / WebLLM):

### 1. 🎲 "Abhyas Bibhyas" – The Adaptive Board Game Engine
- **Gameplay Modes**:
  - **Snakes & Ladders (सापशिडी)**: Land on tiles to unlock multi-modal micro-challenges.
  - **Treasure Quest (खजिन्याचा शोध)**: Complete math, language, and science clues to find the hidden chest.
  - **Spin the Wheel (ज्ञान चक्र)**: Fast-paced daily homework revision wheel.
- **Dynamic Themes**: Jurassic / Dinosaurs, Chhota Bheem & Indian Heroes, Space Explorer, Panchatantra / Jungle, Superhero Quest.
- **Three Input Context Modes**:
  1. *Syllabus Mode*: Select Board (State/CBSE), Medium, Grade, Subject $\rightarrow$ Auto-generate standard-aligned quests.
  2. *Homework Scan Mode*: Snap a photo or paste homework text $\rightarrow$ Instantly gamifies tonight's assignment.
  3. *QR Code Mode*: Scan textbook DIKSHA / Balbharati QR codes $\rightarrow$ Loads chapter-specific games.
- **Multiplayer & Sibling Equalizer**: Allows a 6-year-old and a 10-year-old to play together, dynamically calibrating questions to each child's grade level.

### 2. 🧩 "Shabda Maya" (शब्द माया) – Regional Language Crosswords & Word Grids
- Generates dynamic, printable, and interactive crossword puzzles, word-hunt matrices, and anagram scrambles from textbook vocabulary (*समानार्थी, विरुद्धार्थी, वाक्प्रचार, म्हणी*).

### 3. ⚔️ "Vyakaran Champion" – Drag-and-Drop Grammar Arena
- Fast-paced, tactile games for grammar classification:
  - Gender sorting (*पुल्लिंग / स्त्रीलिंग / नपुंसकलिंग*)
  - Number sorting (*एकवचन / अनेकवचन*)
  - Parts of Speech (*नाम, सर्वनाम, विशेषण, क्रियापद*)
  - Punctuation placements (*विरामचिन्हे*).

### 4. 🎭 "Patra Sanvad" (पात्र संवाद) – Character Roleplay Tutors
- Voice-enabled interactive dialogues with historical and literary characters (e.g., *Tenalirama, Savitribai Phule, Hirakani, Birbal, Sir C. V. Raman*) answering student questions in-character.

## 🤖 LLM Prompts & Study Workflows for Parents & Teachers

### 1. 24/7 Socratic Homework Tutor (RAG Prompt)
```text
System: You are an encouraging, patient teacher trained in NEP 2020 pedagogy for Grade [Grade] in [Medium/Language].
Context: [Attach Chapter Markdown]
Instruction: A student asks: "[Student Question]".
Guide them step-by-step without giving direct answers immediately. Ask probing questions, use relatable real-life analogies, and keep language warm and encouraging.
```

### 2. Differentiated Practice Worksheet Generator (Blooms Taxonomy Aligned)
```text
Context: [Attach Lesson Content]
Task: Create a 3-tier printable worksheet:
- Tier 1 (Knowledge/Recall): Match the following, Fill in the blanks (4 marks)
- Tier 2 (Understanding/Application): Short answers, Sentence making, Grammar drills (6 marks)
- Tier 3 (HOTS - Higher Order Thinking / Creative): "Imagine you were in the story...", "Draw and label..." (5 marks)
Include a Parent/Teacher scoring key with common misconceptions.
```

### 3. Multi-Modal Homework Transformer Prompt
```text
Task: Take this boring rote homework: "[e.g. Write table of 8, learn 5 Marathi spellings]"
Convert it into 4 multi-modal "Abhyas Bibhyas" game cards:
1. Verbal challenge
2. Physical/Kinesthetic challenge
3. Drawing/Spatial challenge
4. Notebook writing challenge
```
