# इयत्ता ३ री परिसर अभ्यास (Environmental Studies - EVS) पाठ्यपुस्तके व स्रोत

महाराष्ट्र राज्य पाठ्यपुस्तक निर्मिती व अभ्यासक्रम संशोधन मंडळ (बालभारती) द्वारे प्रकाशित इयत्ता ३ री परिसर अभ्यास या विषयाच्या दोन्ही पाठ्यपुस्तकांचे संपूर्ण युनिकोड (Devanagari Markdown) डिजिटायझेशन.

## समाविष्ट पाठ्यपुस्तके:

### १. भाग १ (विज्ञान व भूगोल) - आपल्या सभोवतालचे जग
- **एकूण पाठ:** १२
- **संकलित फाइल:** `Grade_3_EVS_Part1_Complete.md`
- **घटक:** हवा, पाणी, माती, ज्ञानेंद्रिये, स्वच्छता व सुरक्षितता, सूर्य-पृथ्वी-चंद्र, वनस्पती, निवारा, कचरा व्यवस्थापन, प्राणी, लोकजीवन, ऋतू व पोषाख, आहार, साधी यंत्रे व भौतिक गुणधर्म, जिल्हा नकाशा वाचन.

### २. भाग २ (इतिहास व नागरिकशास्त्र) - आपल्या सभोवतालचे जग
- **एकूण पाठ:** १३
- **संकलित फाइल:** `Grade_3_EVS_Part2_Complete.md`
- **घटक:** आपले कुटुंब, कुटुंब वंशावळ, माझी शाळा, बाजार, गरजा व समस्या, जलसाक्षरता, भारतीय परंपरा व विविधता, दळणवळण, ऐतिहासिक वास्तू, शौर्यगाथा व क्रांतिकारक, पर्यावरण रक्षण, राष्ट्रीय एकात्मता.
